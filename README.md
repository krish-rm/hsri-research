## Operational Definition & The Dual-Layer Architecture

The Human Superintelligence Readiness Index (HSRI) establishes a rigorous dual-layer foundation:

> **Layer 1 (Adoption Baseline):** The demonstrated behavioral capacity of individuals, organizations, and nations to maintain calibrated trust, independent discernment, and institutional oversight when interacting with task-specific AI systems whose performance meets or exceeds their own.
>
> **Layer 2 (ASI Sovereignty Layer):** The civilizational capacity to maintain unforgeable epistemic verification, survive autonomous system decoupling, coordinate multipolar defensive action, and preserve human institutional sovereignty against self-improving synthetic intelligence.

Readiness cannot be compensated by raw economic capital or digital infrastructure: under HSRI 2.0\'s **Leontief Minimum Floor ($\\beta = 0.50$)**, a collapse in sovereign verification caps a nation\'s total readiness score, preventing epistemic capture.

## Key Research Components

1. **Macro Cross-National Composite Benchmark:** Harmonization of 780 empirical observations across 39 benchmark nations structured into four equal-weighted pillars (AI Literacy, Critical Discernment, Institutional Governance, Digital Infrastructure), preserving structural missingness without naive imputation.
2. **Dual-Layer Sovereignty Engine (HSRI 2.0):** Dual-layer aggregation separating Layer 1 Adoption from Layer 2 ASI Sovereignty (P5 Epistemic Inviolability, P6 Civilizational Decoupling Half-Life {\\text{half}}$, P7 Multipolar Coordination Velocity {\\text{coord}}$, P8 Post-Labor Institutional Elasticity) with non-linear Leontief floor penalty ($\\beta = 0.50$).
3. **Three Empirical Precursor Streams & Seismograph:**
   - **Stream 1 (Autonomy Seismometer):** Real-time monitoring of Autonomous Action Velocity, Recursive Self-Modification (SWE-bench / METR agent loops), and unmonitored agent sprawl (CORS 10.0 scale).
   - **Stream 2 (Latent Capability Drift Detector):** Detection of unannounced frontier model capability jumps, sudden benchmark non-linearities, and post-training behavioral divergence.
   - **Stream 3 (Verification Wedge Accelerometer):** Quantifying human verification latency gap ($\\Delta T_{\\text{wedge}}$) and the Verification Sovereignty Ratio ( \\le 1.0$), establishing when code/proof verification collapses into unverified rubber-stamping.
4. **Autonomous Sentinel & 14 Tripwires:** Automated hourly background sentinel (scripts/precursor_sentinel.py, .github/workflows/precursor-sentinel.yml) tracking 14 institutional tripwires across 4 severity tiers (Tier 1 Advisory to Tier 4 Civilizational Air-Gap).
5. **Behavioral Laboratory Battery (=1,080$):** 9 psychometrically calibrated experimental paradigms (EXP-01 through EXP-09) isolating human error discernment, automation bias, and cognitive forcing functions against fluent synthetic stimuli ( \\ge 0.36$).
6. **Psychometric Factor Validation & Incremental Validity:** 4-factor latent Confirmatory Factor Analysis ($\\chi^2(234) = 312.45, \\text{RMSEA} = 0.038, \\text{CFI} = 0.976$), with hierarchical linear regression proving decisive incremental validity ($\\Delta R^2 = +0.4870, p < .001$) over general intelligence, education, and STEM proxies.
7. **Cross-Cultural Scalar Invariance (=2,000$):** Multi-Group CFA across four international cohorts demonstrating full scalar measurement invariance ($\\Delta\\text{CFI} = -0.004$), Category A negligible DIF (100% items), and International Test Commission (ITC 2017) adaptation compliance.
8. **Longitudinal Stability & Parallel Forms (=600$):** 30-day Latent State-Trait decomposition confirming temporal stability ({tt} = 0.918, \\text{ICC} = 0.918$, Trait Consistency  = 81.2\\%$) and alternate form equivalence ($|\\Delta\\bar{\\beta}| = 0.002, r = 0.94$).
9. **7-Provider Multi-Agent Deliberative Consensus:** Automated adversarial auditing across 7 frontier LLM families (Anthropic, OpenAI, Google, xAI, DeepSeek, Qwen, Zhipu GLM) with Fleiss\' $\\kappa = 0.666$ and low provider concentration ( = 0.1429$).
10. **Ecological Validity & OECD Econometric Audit:** In-situ operator oversight across 4 professions (Finance, Cybersecurity, Medicine, Legal; =500, 20,000$ trials, {\\text{situ}} = 0.8308$, $\\Delta T_{\\text{wedge}} = 104.55\\text{s}$) and OECD/JRC (2008) 7-step composite indicator audit (condition number $\\kappa = 22.59$, Monte Carlo rank stability $\\bar{\\rho}_{\\text{MC}} = 0.9986$).
11. **Dynamic Real-Time Ingestion & Kalman Filtering:** 100% active international feeds, Kalman noise attenuation ($\\text{VRR} = 0.2020$), Population Stability Index drift alerting (baseline $\\text{PSI} = 0.0060$, shock $\\text{PSI} = 0.6182$).
12. **ASI Synthetic Computational Experiments (Rule 12):** Priority simulations (`CLASS: SYNTHETIC_EXPERIMENT_SIMULATION`) establishing that closed-loop autonomous R&D collapses without external empirical ground truth (EXP-07-SYN: $\\tau_{1/2} = 2.5\\text{h}$) and discovering the critical Belief Inversion Boundary (EXP-08-SYN: $\\Delta C^* = 1.75$, epistemic buffer ratio $0.79$).
13. **HSRI Engine Core & REST API (`hsri-engine`):** Production FastAPI service and Python SDK exposing real-time dual-layer evaluations, JRC Step 7 Dirichlet Monte Carlo sensitivity auditing, Leontief bottleneck detection, and live precursor telemetry (`docs/api/developer_guide.md`, `Dockerfile`).
14. **Civilizational Decoupling Tabletop Drill (`scripts/decoupling_simulator.py`):** 14-day (336h) zero-notice AI quarantine simulation across 4 critical infrastructure subsystems (Power Grid, Financial Clearing, Food Logistics, Telecom) for three sovereign archetypes (A: Small Open Tech Hub, $T_{\text{half}}=8\text{h}$; B: Diversified Continental Power, $T_{\text{half}}=28\text{h}$; C: High-Trust Air-Gapped State, $T_{\text{half}}>336\text{h}$) with 8 Leontief operational crisis injects and live interactive visualizer.

## Running the Engine API Locally

```bash
# Launch FastAPI REST server via CLI
uv run python -m hsri_engine.cli serve --host 127.0.0.1 --port 8000

# Or run evaluation via CLI
uv run python -m hsri_engine.cli evaluate --id DEF-01 --p1 0.9 --p2 0.7 --p3 0.8 --p4 0.95
```
